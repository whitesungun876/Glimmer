# Daily Spark — 微光发现（积极心理学版）

## 输入

- 用户当日晨间/晚间文本
- 词库：VIA 人格力量（拾光语境精选）

## 词库（GLIMMER_LEXICON）

| 维度 | 词汇 | 语义说明 |
|------|------|----------|
| 智慧 Wisdom | 好奇心、洞察力、开明、远见 | 对世界的探索与思考 |
| 勇气 Courage | 坚毅、真实、勇敢、活力 | 面对困难时的内在力量 |
| 仁爱 Humanity | 共情力、友善、爱与被爱 | 与他人建立连接的能力 |
| 公正 Justice | 团队协作、公正、领导力 | 在社会中的位置 |
| 节制 Temperance | 宽恕、谦逊、自我调节 | 与自己相处的平衡 |
| 超越 Transcendence | 审美、感恩、希望、幽默 | 发现生命中的意义与光芒 |

## 输出（严格 JSON）

- **response_format**: `{ type: "json_object" }` 强制模型只输出 JSON，避免正则解析。
- 字段说明：

```json
{
  "core_trait": "从词库选最匹配的一个，或自拟四字以内积极心理学词汇",

  "summary_sentence": "肯定式提问或赋能式回应，关联用户具体行为，≤20 字",
  "abstract_symbol_prompt": "英文短句，minimalist, artistic, high-end photography style"
}
```

## 分析逻辑

1. **底层理论**：VIA 人格力量量表 + 马斯洛需求层次，识别行为背后的积极动机。
2. **视角**：不只看到负面情绪，寻找韧性、审美、自我觉察等积极面。
3. **输出风格**：像心理咨询师一样思考，从「安慰话」升级为「专业洞察」。
